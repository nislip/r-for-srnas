# Statistics for SRNAs
---

This repository is tailored towards SRNAs. It assumes no prior knowledge or coding, data analysis, and predictive modeling.

The primary "programming language" used in this repository is **R**. It is encouraged that all students use the accompanying integrated development environment (IDE) RStudio.

See the section "Getting Started" below for detailed steps on how to get started!

# R for SRNAs - Introduction

This repository is tailored towards SRNAs. It assumes no prior knowledge or coding, data analysis, and predictive modeling.

The primary "programming language" used in this repository is **R**. It is encouraged that all students use the accompanying integrated development environment (IDE) RStudio.

See the section "Getting Started" below for detailed steps on how to get started!

## Getting Started

### Setting up RStudio

1. Using the link provided below, **download the latest version of RStudio**. Regardless of whether or not you are operating off a MacBook, Windows PC, or Chromebook, RStudio is compatible!

    [Download Link for RStudio](https://docs.posit.co/ide/user/download.html)

2. Once RStudio is downloaded, open it. You will be greeted with three windows within RStudio that are important to understand.

    - **Quadrant #1**
    - **Quadrant #2**
    - **Quadrant #3**
